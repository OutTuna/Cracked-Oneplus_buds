# OPPO Enco Air5 Pro for macOS

The standalone app now lives at **[Enco for macOS](https://github.com/OutTuna/Enco-for-macOS)**. See that repository for current releases, screenshots, and the research write-up.

Native macOS menu bar app and Swift controller for OPPO Enco Air5 Pro CN, firmware 158.158.105. ANC / OFF / Transparency, separate earbud batteries, official product artwork, appearance settings, About and signed automatic updates. The CLI also supports firmware queries, EQ and gesture reads. EncoCore provides the protocol and RFCOMM transport independently of the CLI.

Fork of [Vedant1521/Cracked-Oneplus_buds](https://github.com/Vedant1521/Cracked-Oneplus_buds), by Vedant Gupta. The original OnePlus controller is retained as `nordbuds.swift`. The original project declares the MIT license.
